# Microservices Resilience Lab

Spring Boot microservices exercise built around book and pricing services.

## Architecture

The repository contains a book service, a pricing service, Docker Compose configuration, and a load-test script. The book service calls the pricing service through its client configuration.

## What Is Demonstrated

- REST endpoints for books and pricing
- Docker-oriented application configuration
- Application health and service interaction screenshots
- Load-testing support through `loadtest.sh`
- Repository tests for both services

The screenshots are preserved and document the exercise environment; they are not production metrics.
